# Changelog

## 1.0.5

- Restored compatibility with the declared Obsidian 1.6.0 minimum version by avoiding a newer language API.
- Added the unified table expansion, dynamic table enhancement, internal-link tab behavior, and configurable default Reading view introduced in 1.0.4.

## 1.0.3

- Fixed English and Simplified Chinese README links on the Community directory page.
- Documented clipboard access and the plugin's offline privacy behavior.
- Adopted Obsidian DOM helpers and cross-window node checks.
- Wrapped asynchronous copy handlers in void event callbacks.
- Replaced the deprecated `builtin-modules` package with Node.js built-in metadata.
- Removed low-value CSS features that generated compatibility warnings.

## 1.0.2

- Moved static Mermaid and lightbox styles from TypeScript into CSS.
- Replaced custom settings headings with Obsidian's native heading API.
- Updated the manifest description to follow Community directory guidance.

## 1.0.1

- Renamed the plugin to Codex Style Markdown.
- Changed the plugin ID and activation classes to `codex-style-markdown`.
- Added a complete Simplified Chinese README.
- Updated repository, installation, packaging, and release metadata.

## 1.0.0

- Initial public release.
- Added Reading view and Live Preview typography.
- Added code block, table, and image enhancements.
- Added global and per-note activation controls.
- Added responsive, print, and reduced-motion styles.
- Added Mermaid zoom, pan, fit-to-width, and fullscreen controls.
- Added complete Light and Dark content modes.
- Added Graphite, Forest, and Spectrum color palettes.
- Added independent code, table, and Mermaid toolbar settings.
- Added Chinese and English settings.
- Added table copy and bounded table expansion controls.
- Added image and Mermaid mouse-wheel zoom controls.
- Added proportional Mermaid frame scaling without a maximum zoom limit.
- Added new-tab navigation for embedded-note open controls.
- Refined nested-list indentation and level-specific markers.
- Refined Callout and embedded-note presentation.
